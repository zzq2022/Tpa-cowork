看懂现代 AI Agent 能力无限扩展的核心秘密：

1️⃣ **Skills 是什么？**
给 Agent 的一包“说明书 + 脚本”（`SKILL.md` 加配套程序），有规矩有执行力！

2️⃣ **怎么“按需加载”？**
平时上下文只放名字+简介（仅耗费几十 Token）；模型判断需要时，才实时 Reads 完整文件，拒绝爆内存！

3️⃣ **为什么这样设计？**
▸ 省上下文（大幅降成本）
▸ 极高可复用（一次编写到处插拔）
▸ 随取随用（能力无限叠加）
