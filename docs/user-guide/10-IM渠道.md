## 10.1 添加并启动渠道账户

1. 打开左下角「设置」→「IM 渠道」。
2. 选择平台并添加账户，填写该平台要求的凭据。
3. 为账户选择默认 Agent，并按需设置允许的私聊、群聊或频道。
4. 保存后启动账户；状态变为「运行中」后，从对应 IM 给机器人发送一条消息测试连接。

一个平台可以配置多个账户。账户级设置决定默认 Agent、回复模式、是否显示思考、知识空间访问和自动审批等行为；部分平台还支持为特定群组或话题覆盖 Agent。

## 10.2 凭据与接入方式

| 渠道 | 主要凭据或前置条件 | 说明 |
| --- | --- | --- |
| Telegram | Bot Token | 使用长轮询，无需公网回调地址 |
| 微信 | 扫码登录 | 通过 iLink 接入 |
| Discord | Bot Token | 通过 Gateway 连接，可用于私聊、群组和频道 |
| Slack | Bot Token + App Token | 需要启用 Socket Mode |
| 飞书 / Lark | App ID + App Secret | 使用 WebSocket 事件订阅，可选择飞书、Lark 或私有部署域名 |
| QQ Bot | App ID + Client Secret | 支持私聊、群聊与频道场景 |
| Signal | 手机号 + 已连接的 signal-cli | 需要在本机准备 signal-cli |
| iMessage | macOS + imsg CLI | 仅适用于能够访问本机 Messages 数据的 macOS 环境 |
| WhatsApp | Bridge URL + Token | 需要先部署兼容的外部桥接服务 |
| Google Chat | Service Account | Webhook 需要可被 Google 访问的公网地址 |
| LINE | Channel Token + Secret | Webhook 需要公网地址并通过签名校验 |
| IRC | 昵称、服务器及可选 NickServ 凭据 | 通过 TCP/TLS 直连 |

凭据只在设置界面录入。若平台返回未授权或令牌失效，重新生成凭据后在原账户中更新即可。

## 10.3 在 IM 中管理会话

每个 IM 聊天同一时间只绑定一个 TPA CoWork 会话，一个会话也只会交给一个 IM 聊天。这样可以避免同一段回复被多个聊天同时接管。

- 在 IM 中输入 `/sessions` 查看可接管的普通会话，再选择一个会话。
- 输入 `/session <id>` 接管指定会话；输入 `/session exit` 解除绑定。
- 在桌面端打开会话后，可使用「移交到 IM」选择渠道、账户和聊天。移交完成时，IM 会补发最近一轮已完成的回答，正在生成的回答会在稍后继续送达。
- 若另一个聊天接管了同一会话，原聊天会被自动解除绑定，并在渠道支持时收到提示。

IM 渠道会话不能开启无痕模式，因为外部聊天仍可能异步发送新消息。

## 10.4 回复模式与思考显示

每个账户可选择一种 IM 回复模式：

| 模式 | 行为 | 适合场景 |
| --- | --- | --- |
| 按轮次拆分 | 每一轮旁白、工具结果和媒体按生成顺序分别发送；支持流式的平台仍会逐步更新 | 推荐，过程清楚且保留时序 |
| 仅最终回答 | 丢弃工具调用前的旁白，只发送最后一轮回答，媒体在末尾发送 | 希望聊天更简洁 |
| 流式预览 | 把整段回复显示为一条不断增长的消息 | 希望实时看到生成过程；不支持的平台会自动退化为「仅最终回答」 |

「在 IM 消息中显示思考过程」默认关闭。开启后，模型的思考内容会以引用块出现在每轮回复前；若聊天会被多人看到，建议保持关闭。

## 10.5 工具审批与安全

当 Agent 在 IM 对话中调用需要审批的工具时，审批请求会直接发到当前聊天。支持交互按钮的平台可以点选允许或拒绝，其他平台会给出可回复的文本选项。

「自动审批工具」默认关闭。开启后，该账户触发的工具调用无需人工确认，可能执行命令、操作文件或调用外部服务。只应在你完全控制的私聊账户和受信环境中开启；多人群聊不要开启。

Bot Token、App Secret 和 OAuth 凭据不应粘贴到聊天消息、日志或截图中。需要更换凭据时，只在「设置 → IM 渠道」编辑账户。

## 10.6 群聊、知识空间与附件

- 群聊可以按账户设置允许范围；不同平台还可按频道、话题或群组选择 Agent。机器人没有响应时，先确认当前聊天在允许列表内，并检查是否要求 `@` 机器人。
- IM 默认不能访问知识空间。先在桌面设置中为账户开启知识空间访问；群聊还需要在对应聊天输入 `/kb on` 再次确认。输入 `/kb off` 可关闭该群的访问。
- 多数渠道可以原生接收图片、音频、视频和文件。平台不支持某种出站附件时，TPA CoWork 会发送下载链接作为兜底，不会静默丢失结果。
- 渠道对附件大小和类型各有上限；上传失败时可改发较小文件，或在桌面会话中打开生成结果。

## 10.7 常用命令

| 命令 | 作用 |
| --- | --- |
| `/sessions` | 列出可接管的普通会话 |
| `/session [<id>\|exit]` | 查看当前绑定、接管或解除会话 |
| `/projects` | 列出未归档项目 |
| `/project <name>` | 把当前会话归入项目 |
| `/kb [on\|off]` | 查看或调整当前群聊的知识空间访问 |
| `/imreply` | 查看或切换当前账户的回复模式 |
| `/status` | 查看运行状态及当前绑定的 IM 渠道 |

`/agent` 和 `/handover` 不在 IM 内使用。要改变 IM 使用的 Agent，请编辑渠道账户；要从 IM 接管会话，请使用 `/session`。

## 10.8 故障排查

- **账户无法启动**：检查凭据、平台侧 Bot 权限和网络连接；Webhook 平台还要确认公网地址与签名配置。
- **能启动但收不到消息**：确认机器人已加入目标聊天、事件订阅或 Gateway 权限已开启，并检查私聊 / 群聊允许范围。
- **可以回复文字但没有附件**：检查平台文件权限、文件大小和 `server.publicBaseUrl`（需要公网附件 URL 的渠道）。不支持的类型会退化为链接。
- **流式预览没有效果**：该渠道可能不支持消息编辑或 Draft；此时预览模式会按设计退化为「仅最终回答」。
- **服务重启后暂时离线**：启动看门狗会重试最近使用的账户；启用恢复通知后，最近活跃的聊天会收到重新上线提示。
- **审批按钮已失效**：审批可能已超时、在桌面端处理，或会话已被其他聊天接管；重新发送请求即可。
