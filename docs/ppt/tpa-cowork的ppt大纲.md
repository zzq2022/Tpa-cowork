## 第 1 页：TPA-harness工程概述

### 标题
TPA-harness：资管级 Agent 基础设施与底座架构

### 副标题
基于 Tauri 2 + React 19 + Rust 构建的桌面级 AI 协同中枢，提供确定性、高吞吐与多端接入支持

### 详细正文

*   **技术栈与三层架构体系**
    *   **前端（React 19 + TypeScript + Vanilla CSS）**：采用微前端思想搭建，高度重视视觉美感与响应速度，全界面实施暗黑模式与现代流光 Glassmorphism 极致美学设计。
    *   **桌面壳层（Tauri 2 + Rust）**：轻量级跨平台 native 运行环境，资源占用小，启动秒级；剥离 GUI 后可独立以后台 Daemon 或 CLI 运行。
    *   **业务核心层（`ha-core`）**：零 Tauri 依赖的纯粹 Rust 核心库，内建 `EventBus` 事件总线，统一管理所有业务逻辑，实现 GUI/HTTP/ACP 多通道零感知切分。
*   **多模式运行支持（Transport 抽象）**
    *   **GUI 模式**：本地桌面交互，低延迟，支持窗口联动与本地资源无缝调用。
    *   **HTTP / WS Server 守护进程**：支持作为后端服务独立部署，暴露 RESTful & WebSocket API 接口，供资管内部其他系统（如 CRM、OMS、交易前台）无缝调用。
    *   **ACP (Agent Communication Protocol) 模式**：支持 stdio 通讯模式，嵌入其他 Agent 引擎或上层管道作为子模块运行。
*   **代码规范与确定性保障**
    *   Rust 异步环境严禁内联阻塞 IO，所有 SQLite / 文件读写必须走 `run_blocking` 或 `SessionDB::run` 线程池隔离，杜绝 UI 线程死锁与主事件循环停顿。
    *   严格的凭据隔离（OAuth / API Key 全链路脱敏，严禁打印日志），出站 HTTP 流量统一受 `ssrf::check_url` 扫描防范内网穿透与伪造。

## 第 2 页：对话和记忆系统

### 标题
智能对话引擎与多级记忆网络

### 副标题
基于API-Round精准消息拦截与渐进式五层上下文压缩，实现无损长期记忆与高准确度上下文管理

### 详细正文

*   **API-Round 分组与 API 协议准备**
    *   针对大模型 Tool Call 配对严苛的要求，采用 `push_and_stamp` 给每轮消息打上 `_oc_round` 戳，确保 `tool_use` 与 `tool_result` 在上下文裁剪时不被暴力截断导致 API 报错。
    *   在发起 API 请求前，统一调用 `prepare_messages_for_api()` 自动剥离内部元数据，构建纯净的 Provider 协议体。
*   **五层渐进式上下文压缩机制（5-Tier Compact）**
    *   *Tier 1 (微压缩)*：去除重复空白、旧的工具中间尾巴。
    *   *Tier 2 (观察裁剪)*：截断过长工具返回输出，保留头部与尾部关键信息。
    *   *Tier 3 (文件恢复)*：将已被阅读过的大段文件内容转化为轻量文件引用指针。
    *   *Tier 4 (摘要提取)*：对旧对话轮次进行 LLM 语义摘要，生成结构化 Memory Chunks。
    *   *Tier 5 (硬性截断)*：按 Token 预算硬性截断极旧消息，确保不超窗口上限。
*   **动态与静态记忆系统（Memory Engine）**
    *   **Core Memory 静态固定前缀**：保存最核心的个人偏好与资管场景定义，保持 prompt 极高复用率与 Prompt Cache 命中率。
    *   **Dynamic Memory 动态召回**：通过向量相似度与三元组图谱（Claims），按需检索关联历史，进 Prompt 前施加 `<untrusted_external_data>` 隔离信封，防止 Prompt 注入攻击。

### 图形化表达与视觉元素
*   **上下文压缩五级漏斗图（5-Tier Compaction Funnel）**：
    *   从顶部的原始海量 Token 经过 5 层滤镜处理，最终输出高度精炼、高 Prompt Cache 命中率的最终 API Message 序列。
*   **记忆三维结构示意图**：展示 Core Memory（固定基座）、Dynamic Claims（关联图谱）、Unfiltered Recall（原文缓存）的交互关系。

### 版式布局设计
*   **左右双栏结构**：
    *   左栏（50%）：对话引擎与 API-Round 机制、压缩五级漏斗示意图。
    *   右栏（50%）：动态/静态记忆分层设计、Prompt 注入防御信封机制。

## 第 3 页：Skill管理与技能中枢

### 标题
Skill 技能中枢与动态扩展矩阵

### 副标题
从简单 Tool 升级为具备业务 Know-how 的复杂 Skill，打造标准化、模块化、安全可控的技能资产

### 详细正文

*   **Skill 的定义与标准结构**
    *   每个 Skill 均包含 `SKILL.md`（定义自然语言触发条件与业务逻辑）、`tool.json`（定义参数 Schema）及对应可执行代码/脚本。
    *   封装投研分析中常见的高频范式：如个股财报拆解、宏观情绪监控、持仓风险分析等，使大模型获得“行业专家级”操盘能力。
*   **SkillHub 技能市场与三级生命周期**
    *   **内置标准 Skill**：随软件分发的系统级工具（文件操作、浏览器控制、基础搜索）。
    *   **用户自定义 Skill**：研究员在 UI 界面或通过自然语言交互动态创建并保存的新技能。
    *   **SkillHub 三级市场**：支持团队内 Skill 的上传、共享、版本管理与权限分发，实现资管 Know-how 资产化沉淀。
*   **动态加载机制（Tool Search）与安全沙箱**
    *   海量 Skill 场景下，不一次性将所有 Tool Schema 塞入 Prompt，采用按需召回（Tool Search）机制，降低上下文消耗。
    *   所有 Skill 执行严格遵守分类风险评估（Low / Medium / High / Strict），敏感操作强制触发审批流程。

### 图形化表达与视觉元素
*   **Skill 矩阵结构卡片图**：
    *   中间为 【SkillHub 技能中枢】，周围环绕【行情分析】、【研报生成】、【风控感知】、【数据抓取】等技能模块。
*   **Skill 自动化创建与沉淀闭环流程图**：
    *   `自然语言需求` ➔ `Agent 编写脚本` ➔ `沙箱测试` ➔ `封装为 SKILL.md` ➔ `入库 SkillHub`。

    *   栏2：SkillHub 三级市场与自动化沉淀流程。
    *   栏3：动态加载机制（Tool Search）与沙箱安全保障。

## 第 4 页：自主任务与多Agent调度

### 标题
自主任务、多Agent协同与定时执行引擎

### 副标题
从单次对话走向复杂长期任务的离线推进、团队协作与自动化调度

### 详细正文

*   **Subagent 子任务分发与血缘隔离**
    *   面对复杂的资管任务（如跨市场多因子分析、全网舆情监控），主 Agent 通过 `subagent` 工具自动拆解子任务并派发给专职子 Agent。
    *   **独立上下文与单向汇总**：子 Agent 具备独立会话与内存预算，运行过程中的中间变量不污染主会话，终态结果单向回传，保障长任务稳定性。
*   **隔离工作树（Worktree 机制）**
    *   在进行长时间分析、代码生成或文件批量处理时，系统自动建立隔离的 Git Worktree 工作区，隔离临时改动，防止污染主分支与生产代码。
*   **Cron 定时与定时唤醒引擎（Schedule & Cron）**
    *   支持定义 Cron 表达式或一次性计时器，离线无人值守触发。主节点竞选与抢槽机制保障高可用，防止多实例并发冲突。
*   **Plan Mode 计划拦截与 Task 追踪**
    *   复杂任务自动触发 Planning Mode，生成 `implementation_plan.md` 供用户审核后才执行；通过 `task.md` 动态更新进度状态。

## 第 5 页：设置、安全与工具权限管控

### 标题
金融级安全架构与多维工具权限管控

### 副标题
以沙箱隔离、审批引擎与SSRF防护构建纵深防御体系，确保数据不出域、合规无死角

### 详细正文

*   **三级权限模式（Default / Smart / Yolo）**
    *   **默认模式（Default）**：所有编辑与写类操作强制弹窗审批，安全第一。
    *   **智能模式（Smart）**：引入“判官模型”评估确信度；已编辑过的文件再次修改自动放行，高风险操作依然硬拦截。
    *   **全放行模式（Yolo）**：仅限受控自动化脚本使用（全局危险模式需显式勾选并记录审计）。
*   **三张红线防御清单（不可放行）**
    *   **保护路径（Protected Paths）**：`~/.ssh`、`*.key`、`.env`、配置文件等强制拦截，**严禁设置“始终允许”**。
    *   **危险命令（Dangerous Commands）**：`rm -rf`、`git push --force`、删库命令等绝对拦截。
    *   **编辑命令（Edit Commands）**：动态监控文件写与修改动作。
*   **沙箱隔离与出站 SSRF 防护**
    *   所有 Shell 命令与代码脚本必须在受限沙箱中运行。
    *   网络请求必过 `ssrf::check_url` 检查，严禁访问内网敏感 IP 与未授权域名。
*   **无人值守与凭据脱敏（Redact）**
    *   在无人值守（Unattended）状态下，任何触碰审批边界的操作默认 Fail-Closed 拒绝。
    *   所有 API Key、OAuth Token 强制进行脱敏处理，**绝对禁止出现在任何日志、Prompt 或导出文件中**。

### 图形化表达与视觉元素
*   **纵深防御三道盾牌**：
    *   盾牌 1：权限模式与审批引擎（Default / Smart 拦截）。
    *   盾牌 2：三张红线清单（保护路径、危险命令、编辑命令）。
    *   盾牌 3：沙箱物理隔离与 SSRF 出站防火墙。
*   **多端一致审批弹窗示意图**：展示桌面 GUI、Web 端、IM 聊天框同步收到的审批卡片，包含倒计时圆环、操作摘要、拒绝/允许按钮。
*   **凭据安全锁图标**：高亮标出“全链路 API Key 严禁入日志/Prompt”。

*   **上-下结构**：
    *   上半部分：三级权限模式与多端一致审批弹窗流程。
    *   下半部分：三列并排（左：红线清单；中：沙箱与SSRF防护；右：无人值守与凭据脱敏）。

## 第 6 页：实际案例一：金融情感分析体系

### 标题
实际案例一：金融情感分析体系

### 副标题
基于大模型与多维风险感知网络，实现“微观个股打分-中观前瞻预测-宏观风险传导”全闭环量化感知

### 详细正文

*   **一、多维金融情感分析**
    1.  **宏观 (Macro)**：监控全球经济与系统性风险。追踪 VIX（美股恐慌）、US10Y（10年美债）、OVX（原油波动率）与 GVZ（黄金波动率），合成 Fear & Greed 指数并识别 **OVX-VIX 风险传导**（局部能源风险 vs 全球流动性危机）。
    2.  **中观/前瞻 (Meso)**：通过 Polymarket API 监控预测市场与聪明钱押注概率，识别成交量 > 3 倍均值与极值共识（概率 $\ge 85\%$ 或 $\le 15\%$），实时映射地缘/关税事件到资产配置与对冲策略。
    3.  **微观 (Micro)**：自动化抓取个股新闻、公告与央视新闻；利用 LLM 进行 1-5 级极性打分；基于规则与 LLM 识别重组、回购、业绩预增等 15+ 类事件，输出 5 类交易信号与置信度。

*   **二、Skills 体系与工具矩阵**
    *   **个股抓取 (`news_fetcher`)**：按代码/关键词/天数全天候抓取新闻公告并清洗去重。
    *   **情感打分 (`sentiment_scorer`)**：LLM 逐条极性标注，聚合生成 Fear & Greed 情绪指数（带容错兜底）。
    *   **事件识别 (`event_detector`)**：双轨识别金融重大事件，输出交易信号、紧急度与置信度。
    *   **宏观情绪 (`market_fear_index`)**：实时计算 VIX/US10Y/OVX 综合评分与波动率传导。
    *   **预测监控 (`polymarket_monitor`)**：捕捉预测市场聪明钱集中大额押注信号。
    *   **深度分析 (`read-pdf` + `write-report`)**：联动解析财报 PDF，按五步法框架自动输出深度研报。

*   **三、典型实战应用案例**
    1.  **持仓个股舆情体检（以比亚迪 002594 为例）**：抓取近 7 天新闻 ➔ LLM 逐条打分 ➔ 生成 Fear & Greed 情绪指数（如 50/100 中性），对比正负面信息输出观望建议。
    2.  **事件驱动交易机会捕捉（资产重组与回购）**：全网检索事件 ➔ 自动识别“重大资产重组”（如 300067 亿纬锂能），输出“强烈关注”交易信号锁定套利标的。
    3.  **全链路综合决策（宏观 ➔ 前瞻 ➔ 微观 ➔ 深度研报）**：宏观恐慌评估 (`market_fear_index`) ➔ 预测市场扫描 (`polymarket_monitor`) ➔ 个股催化剂捕捉 (`event_detector`) ➔ 联动财报解析自动输出深度研报。

*   **四、Skill 联动的核心价值**
    *   **数据全链路**：从宏观风险、预测概率、微观舆情到财报研报无缝串联。
    *   **决策完整性**：兼顾宏观风控、事件催化与财务基本面验证。
    *   **前瞻性定价**：引入 Polymarket 聪明钱概率定价，克服传统新闻之后知后觉。
    *   **投研效率跃升**：将资料搜集与研报撰写自动化，流程从数天压缩至分钟级。

    *   顶部【宏观-中观-微观】三层感知金字塔（VIX仪表盘 + Polymarket折线 + 个股事件卡）。
    *   中部【六大 Core Skills 技能工具盒】（抓取、打分、事件识别、宏观情绪、预测监控、深度分析）。

## 第 7 页：实际案例二：智能研报分析与自动化

### 标题
实际案例二：智能研报分析框架与自动化生成

### 副标题
基于国泰君安“五步法”投研逻辑与 RAG+Agent 融合架构，打造从海量研报秒级检索到深度报告自动撰写的AI投研引擎

### 详细正文

*   **一、国泰君安“五步法”投研分析方法论**
    1.  **Step 1：信息差 (Data Gap)**：挖掘市场忽视的深层数据与隐藏细节（财报附注关联交易变化、非经常性损益明细、应收账款/存货异常变动及现金流与净利润背离）。
    2.  **Step 2：逻辑差 (Logic Gap)**：纠正市场的常规误读逻辑（典型案例：某消费品公司毛利率下降 2 个百分点，市场看空；深度逻辑为公司主动降价抢占市场份额，销量大增 30% 驱动净利润大幅提升，应坚定看多）。
    3.  **Step 3：预期差 (Expectation Gap)**：量化对比市场一致预期与实际偏离幅度及持续性；无一致预期数据时，自动参考券商预测均值（Wind/iFinD）、行业平均增速、历史趋势及管理层业绩指引。
    4.  **Step 4：催化剂 (Catalyst)**：识别触发市场重估的时间节点。划分为短期（1-3个月财报/订单/回购）、中期（3-12个月新产品/行业拐点/重组）及潜在负面催化剂；聚焦年报季“买预期（11月-次年3月），卖现实（4月）”博弈，锁定4月初5大博弈逻辑（时间窗口雷区、分红高送转、一季报叠加、ST退市风险、机构调仓明牌）。
    5.  **Step 5：结论与风险闭环 (Conclusion & Risk Boundary)**：输出一句话核心观点、3-5个支撑要点、投资评级及跟踪 KPI，同时明确**使前四步逻辑完全失效的核心边缘条件**（如出口管制变化导致核心客户流失等逻辑崩塌事件）。

*   **二、RAG 知识库构建与预处理架构**
    *   **秒级检索处理链**：`process_single_pdf()` 解析 PDF 文本与元数据（股票代码、发布日期、报告类型） ➔ 文本切分与元数据注入 ➔ 构建向量与关系型存储。
    *   **知识库 4 类基础设施**：`index.faiss`（向量索引）、`index.pkl`（docstore元数据）、`chunks.json`（BM25关键词检索）与 `documents.db`（SQLite 文档级元数据记录）。
    *   **双引擎混合检索与 RRF 排序**：通过 FAISS 向量语义检索 + BM25 关键词检索，配合 **RRF (Reciprocal Rank Fusion) 融合排序**，实现海量研报与财报上下文的秒级精确召回。

*   **三、AI 研报撰写 Agent 搭建与策略控制**
    *   **System Prompt 即思维操作系统**：将“五步法”投研策略深度嵌入 Agent 提示词（定义规划、多轮迭代收集、五步法输出三阶段），作为 Agent 的思考法则。
    *   **三阶段自动化流程**：
        1.  *规划阶段*：识别分析对象与场景类型（个股深度/季报速评/行业比较/事件驱动/财务异常），定制搜索序列。
        2.  *迭代式信息收集*：调用 `query_pdf` 与 `web_search` 展开多轮递进搜索（基于首轮线索追加二轮追查，避免单轮即停）。
        3.  *五步法深度输出*：结构化生成包含“五步分析 + 交易信号 + 风险闭环”的 15+ 页 Markdown/Word 深度研报。

*   **四、核心业务价值**
    *   **逻辑严密**：克服传统 AI 生成内容的空洞套话，严密套用顶级券商投研“五步法”框架。
    *   **高效可靠**：RAG 知识库秒级提取关键财报附注细节，彻底消除大模型数值与财务幻觉。
    *   **风险可控**：建立显性逻辑失效条件与跟踪 KPI，确保投资决策具备完备的风控闭环。
