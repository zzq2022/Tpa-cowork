# 左侧功能导航展开态设计

## 背景

TPA CoWork 当前使用 76px 宽的纯图标功能栏。入口数量较多，用户必须依赖图标记忆或逐项悬停才能理解功能，降低了首次使用时的可发现性。本次优化为每个入口常驻显示名称，同时保持桌面工作台的轻量感和主内容区空间。

## 目标

- 默认直接显示各入口名称，降低识别和学习成本。
- 保留紧凑纯图标模式，满足小窗口和熟练用户的空间需求。
- 沿用现有浅色表面、细分隔线和克制的交互风格。
- 不改变现有导航目标、菜单能力、通知语义或权限边界。

## 非目标

- 不调整页面信息架构或新增导航入口。
- 不重做品牌色、字体或全局设计系统。
- 不在导航项内常驻第二行功能描述。
- 不改变会话侧栏及主工作区的内容结构。

## 整体方案

功能栏提供 `expanded` 与 `collapsed` 两种显示状态：

- `expanded`：宽度 144px，常驻显示图标与完整功能名称，为默认状态。
- `collapsed`：宽度 76px，沿用当前纯图标布局。

用户可通过栏顶部靠右的收起/展开按钮切换。用户主动选择需持久化，并在后续启动时恢复。响应式自动收起只影响当前窗口呈现，不覆盖已保存的用户偏好。

## 信息结构

导航沿垂直方向分为三组，组间使用现有轻量分隔线：

1. 核心工作
   - 会话
   - 知识空间
   - 成果
   - 定时任务
   - 数据看板
2. 能力与记录
   - 技能广场
   - 我的技能
   - 计划
   - 日志
3. 个人与系统
   - 个人资料
   - 外观
   - 语言
   - 帮助
   - 设置
   - 关于

第三组继续固定在底部。服务状态保留在底部区域，并与个人设置入口保持现有邻近关系。

## 视觉规格

### 展开态

- 容器宽度：144px。
- 导航项保持紧凑单行结构，图标左对齐、名称右置。
- 图标使用统一尺寸，文字使用桌面导航的小号正文层级。
- 名称保持单行；中英文均不得截断核心含义。
- 当前页使用品牌靛蓝色浅背景，图标与文字使用同一强调色。
- 非当前页统一使用中性灰，不再为不同功能入口分配不同强调色。
- Hover 仅加深背景，不增加边框、描边、阴影或缩放。

### 收起态

- 容器宽度：76px。
- 图标、徽标、状态点和底部 Logo 维持当前视觉位置。
- Tooltip 显示“功能名称｜简短用途”，不只重复入口名称。
- Tooltip 继续复用项目的 `IconTip` / Tooltip 公共组件。

### 切换控件

- 位于功能栏顶部靠右，不占用业务导航项位置。
- 展开态显示“收起导航”语义，收起态显示“展开导航”语义。
- 使用统一图标按钮和现有焦点协议。

## 交互与状态

1. 首次使用且无历史偏好时采用展开态。
2. 用户手动切换后，立即更新界面并异步持久化。
3. 持久化失败时恢复上一个用户状态，并记录不含敏感信息的 UI 错误日志。
4. 窗口低于响应式阈值时，界面临时进入收起态。
5. 窗口恢复到阈值以上时，恢复用户保存的状态。
6. 响应式自动收起不得写回偏好，避免小窗口永久改变用户设置。
7. 宽度与内容透明度使用约 180–220ms 的平滑过渡，仅动画化 width/opacity 等轻量属性。
8. 遵循系统的 reduced-motion 偏好；减少动态时直接切换或显著缩短动画。

## 现有能力兼容

以下行为在两种显示状态下必须保持：

- 普通会话与定时任务未读徽标。
- 会话、定时任务的右键菜单。
- 服务运行状态及其设置跳转。
- 主题循环切换。
- 语言浮层及跟随系统选项。
- 帮助窗口、设置、关于页和更新提示。
- 用户头像及个人资料入口。
- 键盘焦点顺序、Enter/Space 激活与可访问名称。

## 组件边界

- `IconSidebar`：负责布局、分组和两种显示状态的呈现。
- 显示状态 hook：负责读取、保存用户偏好并监听状态变化；不负责响应式判断。
- 响应式判断：只计算当前有效显示状态，不修改持久化偏好。
- 导航项内部抽象：统一图标、文字、选中态、Tooltip 和徽标插槽，减少现有重复样式。

本次抽象仅服务功能栏，不扩展为全局导航框架。

## 文案与国际化

- 所有新增按钮名称、Tooltip 用途、展开/收起提示须同步简体中文、繁体中文和英文。
- 英文名称以 144px 宽度下的单行可读为验收目标；必要时使用项目认可的短名称，不以省略号隐藏关键语义。
- 图标按钮必须有与可见文案一致的 `aria-label`。

## 验收标准

- 1024px 及以上常用桌面宽度下，默认显示 144px 展开导航，主工作区无横向溢出。
- 所有现有入口均显示完整名称并可正常跳转。
- 用户手动收起后，重启应用仍保持收起态。
- 窄窗口自动收起后再放宽，恢复此前保存的用户状态。
- 展开与收起过程中无明显跳动，未读徽标和状态点不漂移。
- 两种状态均可完全通过键盘操作，并具有准确的屏幕阅读器名称。
- 浅色、深色和跟随系统主题下，选中态与普通态均保持足够对比度。
- 三种支持语言下无异常截断、重叠或菜单遮挡。

## 验证范围

- 组件测试：默认状态、持久化恢复、切换失败回滚、响应式临时收起。
- 交互测试：所有导航入口、右键菜单、语言浮层、Tooltip、键盘操作。
- 视觉检查：1024px、1280px、1440px 及窄窗口；浅色与深色主题；三种支持语言。
- 回归检查：未读徽标、服务状态、更新提示和会话内容宽度。

## 已确认决策

- 采用固定文字侧栏方案。
- 默认展开，并提供手动收起能力。
- 记住用户上次的手动选择。
- 展开态只常驻显示名称，详细用途放入 Tooltip。
- 窄窗口采用临时自动收起，不覆盖用户偏好。
