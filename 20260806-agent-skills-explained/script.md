# 🎬 视频分镜与口播脚本

- **主题**：《Agent 里的 Skills 是怎么工作的》
- **视觉风格**：`swiss-minimalism`（极简瑞士国际主义：素白纸 `#fbfbfb` + 近黑墨 `#111111` + **信号红 `#E53935` 点睛**，12 列严格网格，无圆角/无渐变/无阴影）
- **旁白模式**：TTS 自动语音合成
- **交付比例**：4K Master + 1080p，帧率：60 FPS（保障图形动效极其顺滑）

---

## 逐帧蓝图 (Storyboard Blueprint)

### Scene 01: 痛点引入与核心外挂 (00:00 - 00:10)
* **视觉画面**：12列极简网格线背景，中央同心圆点阵几何擦除揭示。中间高亮显示 `Agent` 核心控制块，周围弹出各种外部能力组件。信号红线条连接。
* **旁白**：“你有没有想过，大模型本身不会画图表、不会查复杂文档，它是怎么突然掌握这些专业技能的？答案就是——Skills 技能包！”
* **动效说明**：`clip-path` 同心圆扩散 reveal，信号红连线由点向外延伸绘制（SVG `stroke-dashoffset`）。
* **屏幕字幕/花字**：Agent 的“技能外挂”

---

### Scene 02: 什么是 Skills？说明书 + 脚本 (00:10 - 00:30)
* **视觉画面**：左侧出现极简 `SKILL.md` 规范文本框（JetBrains Mono 字体），右侧分支展开 `scripts/` 与 `references/` 配套资源链。信号红标注重点字段 `name` 与 `description`。
* **旁白**：“第一点：Skills 到底是什么？简单来说，它就是给 Agent 的一包‘说明书 + 脚本’。核心是一个 `SKILL.md` 文件，里面清楚写明了这个技能能干什么、什么时候用，以及调用的具体规则；配合脚本文件，直接执行任务。”
* **动效说明**：文本逐行平滑揭示，重点标记框用信号红框线瞬时扫过。
* **屏幕字幕/花字**：Point 1: 说明书 + 脚本 (SKILL.md + 业务代码)

---

### Scene 03: 按需加载 Lazy Loading 机制 (00:30 - 00:50)
* **视觉画面**：对比视觉。上方：臃肿的大上下文窗口（信号红警示线爆表）；下方：极简瑞士网格列表，平时只装载 `[name + description]` 仅占用数个 Token。当鼠标点亮信号红焦点时，完整 `SKILL.md` 瞬间平滑展开。
* **旁白**：“第二点：它是怎么‘按需加载’的？如果把几万字的说明全塞进对话，上下文窗口早就爆了！所以平时，Agent 上下文里只保留技能的名字和一句话简介。只有当模型判断当前任务需要时，才会实时把完整说明读进来使用！”
* **动效说明**：延迟加载（Lazy Load）示意图，按需触发时信号红数据流瞬间填充。
* **屏幕字幕/花字**：Point 2: 按需加载 (平时存索引 -> 触发读全文)

---

### Scene 04: 为什么这样设计？三大优势 (00:50 - 01:10)
* **视觉画面**：分栏三列极简卡片，纯红黑白撞色反差。三列分别展示计数器动画：1. Token 节省率 -85%；2. 跨 Agent 组合模块；3. 即插即用插拔图标。
* **旁白**：“第三点：为什么要这样设计？第一，极度省上下文，大幅降低推理成本；第二，模块化可复用，一次编写全平台通用；第三，随取随用，像插件一样让 AI 动态进化！”
* **动效说明**：三列依次由下向上弹入，数字计数器从 0% 跳动到 85%。
* **屏幕字幕/花字**：Point 3: 省上下文 · 高可复用 · 随取随用
