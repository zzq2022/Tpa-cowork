# 06 · SkillHub 与技能市场

**SkillHub** 与 **我的技能 (MySkills)** 为 TPA CoWork 用户提供了全方位的 AI 技能扩展能力。你可以从云端 SkillHub 技能大盘中一键探索、预览并下载由社区与团队共享的最新 Agent 技能，也可以在“我的技能”中管理本地安装的技能、创建自定义技能并将其提交发布到云端。

**入口**：
- 侧边栏图标栏的「SkillHub」（技能云市场大盘）
- 侧边栏图标栏的「我的技能」（本地技能管理与云端同步）
- 设置 → 「技能」配置面板

## 6.1 SkillHub 云端技能市场

SkillHub 是 TPA CoWork 的云端 Agent 技能发现与共享平台。通过 SkillHub，AI 助手不再局限于固定的初始能力，而是可以按需获取扩展能力（如专门的编程工具、文档处理、业务流程自动化等）。

### 云端账号与会话登录
- 在 SkillHub 视图右上角或设置的「个人资料 (Profile)」面板中，你可以登录或注册 SkillHub 平台账号。
- 登录后，你的身份 Token 将在本地加密保存，支持跨会话自动刷新与安全退出。
- 登录账号后，即可解锁“我的技能”云端发布提交、状态审核跟踪以及私有/团队技能同步等功能。

---

## 6.2 搜索、筛选与技能详情

在侧边栏点击 **SkillHub** 即可打开技能云市场大盘：

1. **多维分类筛选**：大盘顶部提供分类标签（如：工具扩展、开发者辅助、办公自动化、数据处理等），点击即可快速过滤。
2. **关键词搜索**：在搜索框中输入技能名称、作者或功能描述，实时检索相关公开技能。
3. **热度与排序**：支持按“最受欢迎”（下载量）、“最高评分”（点赞数）、“最多浏览”及“最新发布”进行多维度排序。
4. **技能卡片与 README 预览**：
   - 点击任意技能卡片即可打开**技能详情弹窗**。
   - 详情页中完整渲染格式化的 Markdown 说明文档 (`SKILL.md` / `README.md`)，清晰展示技能适用场景、工具触发指令、作者 Username、更新时间及版本号。

---

## 6.3 一键下载与安装

发现心仪的技能后：
1. 点击详情页或卡片上的 **“下载/安装”** 按钮。
2. 系统会自动请求云端服务器并解压提取技能文件，安全安装至本地数据目录下的 `~/.tpa-cowork/skills/<skill-slug>/` 目录。
3. 如果本地已存在同名或旧版本技能，系统会弹出升级覆盖提示，确保无缝完成更新。
4. 下载完成后，该技能即刻在本地生效，无需重启应用即可在对话中被 AI 自动识别或调用。

## 6.4 我的技能 (MySkills) 管理

在侧边栏点击 **我的技能** 进入本地技能管理中心：

- **本地技能总览**：清晰列表展示所有当前已安装的技能（包含系统预设技能与自定义/已下载技能）。
- **开关切换**：每个技能右侧提供独立的“启用/禁用”开关。禁用后，AI 助手在对话中不会自动加载该技能的 Prompt 提示词与工具能力。
- **配置与修改**：点击技能条目可查看其详细文件结构、内部引用的工具及依赖选项。

---

## 6.5 技能创建与可视化编辑

想让 AI 助手掌握符合你个人工作流的特定能力？你可以直接在“我的技能”中创建新技能：

1. 点击顶部 **“新建技能”** 按钮。
2. 填写技能的基本元信息：技能标识 (Slug)、显示名称、分类、版本以及功能描述。
3. 使用内置的结构化 Markdown 编辑器编辑 `SKILL.md`：
   - 编写 Prompt 引导词（规定 AI 在什么场景下、如何响应此类任务）。
   - 定义引用的系统工具或自定义脚本。
4. 保存后，本地技能即刻生效并加入“我的技能”列表。

---

## 6.6 发布技能至 SkillHub 云端审核

如果你创建了一个优秀的技能并希望分享给社区或团队成员：

1. 在“我的技能”列表中，找到你需要发布的自定义技能。
2. 点击 **“发布到 SkillHub”** 按钮。
3. 校验账号登录状态后，系统会将该技能的打包元数据与 `SKILL.md` 提交至 SkillHub 云端服务器。
4. 提交后，技能状态会同步标示为 **待审核 (`pending-review`)**。
5. 审核通过后，状态自动变为 **已发布 (`published`)**，并正式在 SkillHub 市场公开供全球用户搜索与下载；如因违规或格式问题被拒绝，系统会反馈具体的驳回原因 (`rejected`) 供你修改后重新提交。

---

## 6.7 技能版本升级与新鲜度检测

- 系统后台会自动定期对比本地已安装技能的基线版本与 SkillHub 云端的最新版本。
- 当检测到已下载技能存在云端新版本更新时，“我的技能”列表中对应条目会显示 **“可升级”** 提示角标。
- 点击 **“一键更新”** 即可秒级获取最新版本的技能定义与优化，让你的 Agent 技能保持最新状态。

## 6.8 技能自我进化与草稿净化

除了手写创建与云端下载外，TPA CoWork 具备独特的 **“自我进化 (Skill Evolution)”** 机制。AI 在与你的日常协作中，能够自动感知重复工作模式，并将经验自动提炼、沉淀并净化为新技能。

**入口**：设置 → 技能 → **自我进化** 标签页。

### 1. 对话经验自动提炼
- **自动化分析**：每当会话中发生频繁的工具调用、长工作流或用户纠错时，后台分析模块会回看对话内容。
- **自动生成技能草稿**：系统会自动提取有价值的操作步骤、命令参数与提示词模式，自动整理生成 `SKILL.md` 并落入 **“待审核技能草稿”** 列表。

### 2. 草稿合并与自动净化 (Skill Curator)
- **主题聚类去重**：随着对话增加，系统可能会产生多条相似主题的草稿。设置中的 **Auto-curator（草稿合并器）** 会定期扫描现有草稿，自动识别重叠、相近的技能聚类。
- **一键合并与净化**：系统会给出“建议保留 1 条核心技能、删除其余重叠项”的优化方案，防止本地技能库臃肿或同类技能冲突，保持技能库的高纯度。

### 3. 质量门槛与自动激活控制
- **质量门槛校验 (Gates)**：提炼过程中自动过滤掉缺乏具体命令/代码的空洞内容、对短对话的简单复述或复用概率低的内容。
- **新技能自动激活**：
  - **关闭（默认）**：提炼的技能先暂存到“待审核草稿”区，需要你在界面过目后点击“激活”才正式注入系统。
  - **开启**：通过质量校验的新技能自动激活上岗，实现真·越用越懂你的自我进化体验。
